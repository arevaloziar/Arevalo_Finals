# Zia Arevalo's portfolio

This is my IT0043 portfolio page, started from my earlier HTML file. I moved the page, styles, and scripts into separate folders and added a small settings feature.

The theme, visitor name, and last visit are saved together in one Local Storage item. The contact form is only a demo and does not send or save messages.

Open index.html in a browser, or serve the folder with a local web server.
